# P08-M6 — The app on desktop: notifications without a push service

- Date: 2026-11-18
- Plan: [P08-plan.md](P08-plan.md) (D-0094, finding 10); decision D-0098
- Status: built and tested headless; not yet checked on screen on macOS, Windows and Linux.

## What was built

| Piece | Where |
| --- | --- |
| The rule set: what notifies, decided on the device | `apps/ui/src/features/notify.rs` (`decide`) |
| The notifier: permission, badge, notifications, pressing one opens its chat | `apps/ui/src/features/notify.rs` (`install`, `watch`) |
| Arrivals told to the notifier at once | `apps/ui/src/store/mod.rs` (`Arrival`, `arrive`, `on_arrival`); calls in `features/calls/mod.rs` |
| Close to the tray; showing the window again | `apps/ui/src/features/desktop/mod.rs` (`close_to_tray`, `show_main_window`) |
| Open at login, read and set through the system | `apps/ui/src/store/ext_extras.rs` (`set_launch_at_login`, `refresh_launch_at_login`); the tray choice remembered |

## Evidence

| Property | Test |
| --- | --- |

| Each switch (messages, groups, calls, reactions) turns its kind off | `each_switch_turns_its_kind_off` |
| The chat being read is not notified; one in the background is | `the_chat_being_read_is_not_notified_but_a_background_one_is` |

| Sounds follow the setting | `sounds_follow_the_setting` |
| The wiring, on NSH's engine headless: decided at arrival, two in one batch both notify | `the_store_s_events_reach_the_notifier` |

All 121 app tests pass (`cargo test --lib` in `apps/ui`).
