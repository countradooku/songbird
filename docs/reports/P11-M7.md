# P11-M7 — The app: real plans, desktop checkout, Family, standing and appeals, support, invites

- Date: 2026-11-19
- Plan: [P11-plan.md](P11-plan.md) (M7); decision D-0133
- Status: built; headless tests and screenshots pass; the live purchase run waits for a Mollie
  test account (or a local billing with its emulator), and StoreKit 2 and Play Billing wait for
  the native hosts (finding 14, like push).

## What was built (`apps/ui`)

| Piece | Where |
| --- | --- |
| The real backend for plans: entitlement and standing; Mollie checkout with a subscriber secret kept on the device; the subscription's state and cancel; anonymous tokens fetched from billing, **finished against a token key pinned on first sight** (a changed key under the same ID is refused), redeemed on the account; next month's token kept and redeemed in that month | `src/backend/plans.rs` |
| Family on the mailbox: create, a seat per member (link with the seat secret, filled with this month's token), remove; a member joins with the link, claims the seat's token without an account and redeems it; leave | `src/backend/plans.rs`, `src/features/plans/mod.rs` (copy a seat's link; join / leave) |
| Support: tickets sealed to the support key on the device, a reply key per ticket kept here, read / close; the Help form's **"About my account"** choice (signs the ticket only then) and logs only with consent, exactly the previewed scrubbed text | `src/backend/plans.rs`, `src/features/plans/help.rs`, `src/store/ext_extras.rs` |
| **Limited / suspended**: a banner on Chats and an "Account status" page saying what it means and what still works, with the appeal (a signed `appeal` ticket) | `src/features/plans/standing.rs`, `src/features/chats/mod.rs` |
| Invites: the personal link carries the inviter's card in its fragment; codes made up to the allowance, kept on the device, their status asked by hash | `src/backend/plans.rs`, `src/backend/mod.rs`, `src/features/plans/invites.rs` |
| Limit moments: plan limits (409 `limit`), sizes (413), a full backup space, a suspended or limited account, in plain words that say nothing already there is removed | `src/backend/mod.rs` (`explain`), `src/backend/backup.rs` |
| The plan page's dates from the entitlement's last day | `src/features/plans/mod.rs` |
| Server connection: a billing address field | `src/features/server.rs`, `Endpoint::billing` |
| `api`: `GET /v1/entitlements` also says the standing | `services/api/src/plans.rs`, PROTOCOL §14.3 |

When the real backend is off, every screen keeps its mock, as before.
