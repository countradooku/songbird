## Changes from the plan

- **PROTOCOL §14, not §12:** §12 and §13 (versioning, test vectors) are cited by number across
  the code; Prompt 11's section is appended instead of renumbering them.
- **Which services follow the snapshot.** `api` follows it (every limit is enforced there,
  including the call endpoints: the `calls` service holds no registry and enforces nothing
  per account). The worker sweeps the table. `delivery` starts following it in M5, when
  standings give it something to enforce; following it now would be dead code.
- **The old configuration numbers became ceilings** rather than disappearing, so a deployment
  (and the existing tests) can still cap any plan; their defaults were raised so the plans
  decide (devices 16, files 4 GiB, bytes 1 TiB a day, vault 1 TiB and 10,000,000 chunks).
- **A budget record per level** for bytes and packs: a single record made an upgrade wait for
  the Free budget to refill (found writing the media test). Free keeps the old record names.
- **A device not yet in the signed list** gets 403 `pending` from `GET /v1/entitlements`, as
  from every account read.
