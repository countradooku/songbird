## Properties and their evidence

| Property | Evidence |
| --- | --- |
| The server enforces every rule it can see; no device of the child loosens it | `a_parents_policy_locks_rules_and_only_the_parent_or_the_date_ends_it` |
| Only the parent's signature changes or ends a policy; replays and forgeries are refused | same test |
| Group adds of a supervised child need the parent's approval for that group | `a_supervised_child_joins_a_group_only_with_the_parents_approval` |
| The server holds no parent account or birth date | same test (the row's fields are `flags`, `pkey`, `policy`, `pv`, `unlink_at`) |
| Supervision ends on its date without the parent | same test (worker queries) |
| Client rules are readable only by the two devices | `client_rules_open_only_for_their_child_and_version` |
| Unlink dates and consent ages | `supervision_ends_the_month_after_the_birthday`, `every_member_state_has_an_age_between_13_and_16` |

## GDPR Article 8

The per-country table is in THREAT_MODEL §5, with its status: the range, the default of 16 and
seven countries were confirmed on 2026-11-18; the rest must be confirmed with counsel against
each national law before release.

## Changes from the plan

- Later policies may come from any device: the parent's signature is the authority, so the
  server never learns which account is the parent's.
- Joins by the child itself (by link or request) also need the parent's approval.

THREAT_MODEL §1: parental supervision of a child account. §3.26: six rows. §4: the completed row.
§5: the Article 8 table.
