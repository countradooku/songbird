## The gate's M2 items

| Gate item | Evidence |
| --- | --- |
| **Every permission rule has a negative test on both client harness and server** | `matrix.rs`: add, remove, policy (send, edit info, add, approval, calls), roles (promotion, demotion, owners), stale entries, channels. Each cell is refused on the server (`Forbidden`) and by a client (`verify_commit` with `roles::authorize`), and accepted for a role that may. The cells no commit carries: sending (send path unit test and live, reason 14), editing info (live 403), calls and pin/delete (pure rules, `roles` unit tests; client-only by D-0065 §6). Links and approval: M3. |
| **"Admin approval for new members", "only admins can edit group info", "only admins can send" each map to a cell** | `add` role at Admin (matrix), `edit_info` at Admin (matrix and live metadata 403), `send` at Admin (matrix, send unit test, live reason 14) |
| **Member change history** | The change log: entries signed by the committer, verified by the server, readable by every member device (live) |
| **Lost-device rejoin, if group policy allows** | External commits rejoin an account's devices only (M1). The roles extension cannot change in an external commit (RFC 9420), so rejoins keep the group's roles |
