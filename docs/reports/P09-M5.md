# P09-M5 — The app's settings, app lock, proxy dialing

- Date: 2026-11-18
- Plan: [P09-plan.md](P09-plan.md) (D-0101); decision D-0106; PROTOCOL §10.1–§10.2;
  THREAT_MODEL §3.26 (rows marked M5)
- Status: built and tested; threat-model rows approved by the owner on 2026-11-18 with the gate (D-0109).

## What was built

| Piece | Where |
| --- | --- |
| Every synced setting as an encrypted record; device-only settings saved apart; restart, change, sync every 30 s | `apps/ui/src/backend/records.rs` (`SYNCED`, `DEVICE`, `restore`, `changed`, `schedule`, `periodic`, the HTTP `Remote`) |
| The storage key: given to linked devices, adopted with an empty replica, rotated when the main phone is alone | `records::storage_key`, `adopt_key`, `rotate_key` |
| Server-enforced settings written to the server, reverted in words when refused | `apps/ui/src/backend/account.rs`; store intents `set_discoverable`, `set_message_requests`, `set_groups_add`, `set_inactivity` |
| New rows: typing indicators, find me by username, message requests, delete if I'm away | `features/settings/privacy.rs`, `chats.rs`, `account.rs` |
| Two-step PIN (6 to 12 digits), the account report (the GDPR export summed up), deletion on the server | `backend/account.rs`, `features/settings/account.rs`, `features/devices/account.rs` |
| App lock: six digits, PBKDF2 at 600,000 rounds, waits that survive closing the app, lock at start and after the chosen delay | `backend/lock.rs`, `features/lock.rs` |
| Dialing through a Songbird proxy: TLS-in-TLS, the inner session's channel binding | `crates/client` (`ProxyRoute`), `crates/types/src/proxy_link.rs`, `apps/ui/src/backend/ws.rs` |

## Properties and their evidence

| Property | Evidence |
| --- | --- |
| Every synced and device-only setting round-trips; bad values change nothing | `every_synced_and_device_setting_round_trips`, `bad_values_and_unknown_keys_change_nothing` |
| Device-only settings never become records | `device_only_settings_are_never_records` |
| Two devices converge; saved contacts too | `two_devices_converge_through_the_store`, `saved_contacts_converge_between_devices` |
| Settings survive a restart on the real engine | `settings_survive_a_restart` (headless) |
| Only the passcode opens the app; the passcode is kept as a salted slow hash | `the_app_opens_locked_and_only_the_passcode_opens_it`, `a_passcode_is_kept_only_as_a_salted_slow_hash` |
| Wrong guesses wait longer and longer, and closing the app doesn't reset that | `wrong_guesses_wait_longer_and_longer`, `closing_the_app_does_not_reset_the_wait` |
| A client reaches delivery through a proxy link | `a_client_reaches_delivery_through_a_proxy_link` (e2e, the real relay, a TLS delivery node) |

## Changes from the plan

- Wrong passcode guesses were first counted in memory, so closing the app reset the wait. The
  count and the wait's end are now saved on the device.
- The storage key is rotated only when the main phone is left alone until app-core can send a
  new key to the other devices end to end (A2). PROTOCOL §10.1 says so.
