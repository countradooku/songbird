- Plan: [P08-plan.md](P08-plan.md) (D-0094); decision D-0095; PROTOCOL §1 (`Send` flag `0x80`)

## Properties and their evidence

| Property | Evidence |
| --- | --- |
| A ring is not delayed by a backlog of message wake-ups | `push_live` phase 6: a ring reaches APNs in **52 ms** with 9,984 of 10,000 wake-ups still queued |
| A ring past its time is never sent; a ring to Apple goes to `PushKit` with expiry 0 | `push_live` phase 2 |
| Google and a distributor cannot tell a ring from a wake-up | `push_live` phase 2: FCM and Web Push ring bodies equal the wake-up bodies |
| A burst is at most two wake-ups, byte-identical, and the last message always has one after it | `a_burst_is_one_leading_and_one_trailing_wake_up`; proptests `no_request_is_left_without_a_later_push`, `every_wake_up_has_a_job_at_or_after_it`; `push_live` phase 1; gate `an_offline_device_receives_a_push_end_to_end` |
| A silent send is stored and delivered, and wakes nobody | `a_silent_send_is_stored_and_delivered_but_wakes_nobody`; vector `send_frames_with_hints` (receipt, flags `0x84`) |
| Tokens are out of the registry's database; old rows move once, never over a newer one | `push_registrations_live_apart_and_old_rows_move_once`; `deletion_disables_writes_the_outbox_and_leaves_nothing` |
| Deletion still leaves no token behind | gates `account_deletion_is_verified_across_every_store`, P03 export and deletion, P06 |
| Hanging and reset requests are retries; a black-holed APNs opens the breaker and recovers | `a_black_holed_provider_times_out_opens_the_breaker_and_recovers`, `a_reset_stream_is_retried`, FCM and Web Push `hanging_and_reset_requests_are_retries` |

## Changes from the plan

- The plan's `j:push-call` is named `j:ring`; its jobs carry their deadline, so `push` needs no
  clock agreement beyond NTP's.
- Every bit of the `Send` flags byte is now assigned (the retired `0x01` stays refused).
- SurrealDB's system users have roles, not per-table rights: the three users of the `push`
  database can each read and write it; what they cannot reach is anything else (D-0097).

## Threat-model rows for the owner

`SILENT` on a send; push registrations in their own database; a ring's timing seen by Apple
(THREAT_MODEL §1, and §3.25).
